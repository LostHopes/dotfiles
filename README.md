## Main keybindigs

The rest of the keybinds you can find or change in the sxhkdrc config file.

### Apps

| Action | Hotkey |
| --- | :---: |
| Close the app | ``Super + Q`` |
| Terminate the process | ``Super + Shift + Q`` |
| Terminal | ``Super + K`` |
| Browser | ``Super + B`` | 
| Code editor | ``Super + G`` |
| File manager | ``Super + I`` |
| Volume controller | ``Super + P`` |
| Messanger | ``Super + T`` |
| Music player (Spotify) | ``Super + M`` |
| Reader | ``Super + R`` |
| Notes | ``Super + O`` |

### Miscellaneous

| Action | Hotkey |
| --- | :---: |
| Switch workspaces | ``Super + 1-6`` |
| App launcher | ``Super + Space`` |
| Reload hotkey daemon | ``Super + Esc`` |

### Window rules

| Action | Hotkey |
| --- | :---: |
| Floating/Tiled mode | ``Super + V`` |
| Fullscreen mode | ``Super + F`` |
